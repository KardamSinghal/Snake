# 🐍 Snake Game

A Python-based clone of the classic Snake arcade game, built using **Pygame**. This project offers a fun and interactive way to explore game development fundamentals, including collision detection, dynamic rendering, and user input handling.

![GitHub stars](https://img.shields.io/github/stars/KardamSinghal/Snake?style=social)
![GitHub forks](https://img.shields.io/github/forks/KardamSinghal/Snake?style=social)

## 🎮 Game Overview

Control the snake to eat food, grow longer, and avoid crashing into walls or itself. The game features smooth movement, randomized food placement, and a scoring system that tracks your progress.

## ⚙️ Technologies Used

- **Python**
- **Pygame**

## 🚀 Getting Started

### Prerequisites

Install Python and Pygame:
```bash
pip install pygame
```

### Run the Game

1. Clone the repository:
   ```bash
   git clone https://github.com/KardamSinghal/Snake.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Snake
   ```
3. Run the game:
   ```bash
   python GUI.py
   ```

## 🕹️ Controls

- **Arrow Keys**: Move the snake
- **Q**: Quit the game
